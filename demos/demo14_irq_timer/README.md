# Demo 14：TIM + EXTI + 短按/长按 + 中断优化

## 目标
覆盖图片中的按键单击、长按、定时器精确控制 LED，以及中断延时、捕获和上半部优化。

## 推荐设计
- EXTI：只记录按键边沿并通知任务。
- TIM：提供稳定时间基准或输入捕获。
- KeyTask：在任务中运行短按/长按状态机。
- LEDTask：接收事件队列并执行 LED 动作。

## 状态机
```text
IDLE -> PRESSED -> HOLDING -> RELEASED
                 |             |
                 +--timeout----+
```

## 验收
- 短按只产生一次事件。
- 长按达到阈值只产生一次长按事件。
- 按键抖动不会产生多次误触发。
- ISR 执行时间短，复杂处理在任务中完成。

## 测量
使用 J-Link/Ozone 或 GPIO 翻转测量 ISR 执行时间；不要用串口打印时间代替真实中断耗时测量。
