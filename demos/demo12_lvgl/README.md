# Demo 12：LVGL 移植、LCD、触摸与资源

## 目标
覆盖图片中的 LVGL 初识、目录结构、基础组件、事件、动画、图表、画布、触摸移植、LCD 集成和外部 Flash 资源。

## 分阶段
1. PC/裸机模拟：先创建 Label、Button、Slider。
2. 加入 ST7789 flush 回调。
3. 加入 tick 和 `lv_timer_handler` 任务。
4. 加入触摸 `read_cb`。
5. 练习容器、标签、图片、按键、开关、进度条、滑动条、弧、下拉框、列表、文本框、键盘、消息框、日历、图表和画布。
6. 将图片资源放到外部 Flash；读取前验证地址、长度和 CRC。

## FreeRTOS 任务原则
LVGL 对象默认只由一个 UI 任务访问。传感器任务通过消息队列把数据发送给 UI 任务，不要从传感器 ISR 直接修改 LVGL 对象。

## 显示适配
- `flush_cb` 只负责把区域像素提交给 ST7789。
- DMA 完成后调用对应版本 LVGL 的 flush-ready API。
- 传输缓冲区在 DMA 完成前不得修改。

## 触摸适配
- 读取任务/回调得到坐标和按下状态。
- 做坐标旋转、镜像和边界裁剪。
- 触摸控制器型号未知时，不能直接假定 CST816/FT6236。

## 外部 Flash 资源
- 先验证 SPI Flash JEDEC ID。
- 规划地址表和版本号。
- 写入后读回 CRC。
- UI 只使用已经验证的资源，不直接相信 Flash 内容。

## 验收
- 屏幕显示基础页面。
- 按键或触摸可以触发事件。
- 至少完成一个动画、一个图表和一个画布示例。
- 传感器数据通过队列显示到页面。
